# Установка парсеров (Avito, Яндекс.Карты, HH.ru, Rusprofile)

Четыре десктопных парсера с общей установкой:

- **Avito Parser** — объявления Авито: название, цена, ссылка, локация, продавец, описание.
- **Yandex Maps Lead Parser** — организации с Яндекс.Карт: телефоны, сайты, адреса, соцсети.
- **HH.ru Parser** — вакансии hh.ru: должность, компания, зарплата, контакты (где открыты).
- **Rusprofile Parser** — компании с rusprofile.ru по кодам рубрик (ОКВЭД без точек):
  название, ИНН, ОГРН, статус, дата регистрации, адрес. По умолчанию заполнен «пищевой»
  набор кодов (производство и торговля продуктами питания).

Все результаты сохраняются в CSV, JSON и Excel в папку `results` рядом с программой.

## Что нужно на компьютере

1. **Windows 10/11**.
2. **Python 3.10 или новее** — [python.org/downloads/windows](https://www.python.org/downloads/windows/).
   При установке обязательно поставьте галочку **«Add python.exe to PATH»**.
3. **Google Chrome** — [google.com/chrome](https://www.google.com/chrome/). Парсеры управляют обычным Chrome.

## Установка

1. Скопируйте папку `parsers-setup` (или распакуйте `parsers-setup.zip`) в любое постоянное место,
   например `C:\Parsers`. **Не запускайте установку прямо из zip-архива.**
2. Запустите `install.bat` (двойной клик).
3. Дождитесь надписи `=== Done! ===`. Установщик сам:
   - создаст виртуальное окружение Python (папка `.venv`);
   - установит зависимости (playwright, openpyxl, httpx, scrapy);
   - создаст четыре ярлыка на рабочем столе.

Если Windows SmartScreen предупредит о запуске — «Подробнее» → «Выполнить в любом случае».

## Запуск

Ярлыки на рабочем столе: **Avito Parser**, **Yandex Maps Lead Parser**, **HH.ru Parser**,
**Rusprofile Parser**. В каждом окне: введите запрос (для Rusprofile — коды рубрик), нажмите
«Запустить сбор», заберите Excel из папки результатов.

## Полезно знать

- **Капча.** Если Авито или HH покажут проверку «вы не робот» — просто решите её в открывшемся
  окне Chrome, программа подождёт и продолжит сама.
- **Вход в аккаунт.** Профиль Chrome сохраняется между запусками (папка `tools`). Если один раз
  войти в свой аккаунт Авито или hh.ru в окне парсера, вход сохранится, и данных будет больше
  (например, контакты работодателей на HH чаще видны только после входа).
- **Телефоны на Авито** не отдаются без входа в аккаунт («номер в приложении») — это ограничение
  самого Авито.
- **Скорость.** Режим «Открывать каждую карточку/вакансию» даёт больше данных (продавец, описание,
  контакты), но работает заметно медленнее.
- **«Вся Россия» в Яндекс.Картах.** В поле «Город» можно выбрать **Вся Россия** — парсер сам
  обойдёт 65 крупных городов РФ (от Москвы до Якутска), уберёт дубли и остановится, когда наберёт
  заданный лимит организаций. Чем больше лимит, тем дольше сбор.
- Перенос на ещё один компьютер = снова скопировать папку и запустить `install.bat`
  (папку `.venv` копировать не нужно, она создаётся заново).

## Консольный запуск (для автоматизации)

```powershell
.\.venv\Scripts\python.exe .\avito_parser_app.py --cli --query "пастила" --city "Москва" --limit 100
.\.venv\Scripts\python.exe .\yandex_maps_parser_app.py --cli --query "кофейня" --city "Вся Россия" --limit 300
.\.venv\Scripts\python.exe .\hh_parser_app.py --cli --query "менеджер по закупкам" --city "Москва" --limit 100 --deep
.\.venv\Scripts\python.exe .\tools\rusprofile-scrapper\run_rusprofile_local.py 463900 472900 --max-items 300 --output-dir .\results\rusprofile
```

Для Rusprofile код рубрики — это ОКВЭД без точек: `46.39.00` → `463900`.
